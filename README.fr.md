# Plugin Announce

## Introduction

Le plugin Announce est un systeme de gestion de petites annonces pour la plateforme Lutece. Il permet aux utilisateurs de creer, publier et gerer des annonces organisees par secteurset categories, avec recherche integree, moderation, integration workflow et expiration automatique.

## Fonctionnalites

 **Front-office (XPage)** 

 
* Parcourir les annonces par secteur / categorie
* Recherche plein texte avec filtres (mots-cles, plage de dates, plage de prix)
* Creer, modifier, suspendre et supprimer ses propres annonces
* Formulaire de creation en plusieurs etapes avec champs personnalises (generic attributes)
* Support de diaporama d'images
* Abonnement aux categories ou aux utilisateurs (notifications email)

 **Back-office (Admin)** 

 
* Gestion des secteurs et categories
* Publier / depublier / suspendre les annonces
* Moderation des annonces avant publication (par categorie)
* Integration workflow pour la gestion avancee du cycle de vie
* Permissions RBAC sur les secteurs, categories et annonces

 **Daemons** 

 
*  **Indexeur de recherche** - Indexation Lucene incrementale des annonces (defaut : toutes les 60s)
*  **Daemon d'expiration** - Notifie les utilisateurs de l'expiration prochaine et supprime les anciennes annonces (defaut : 120 jours, configurable)

 **Portlets** 

 
*  *Mes annonces* - Affiche les annonces de l'utilisateur connecte
*  *Dernieres annonces* - Affiche les annonces les plus recentes (nombre configurable)

## Configuration

Proprietes principales dans `announce.properties` :

| Propriete| Defaut| Description|
|-----------------|-----------------|-----------------|
| announce.announce.qty.max| 10| Nombre maximum d'annonces par utilisateur|
| announce.nbDaysBeforeAnnouncesRemoval| 120| Jours avant suppression automatique|
| announce.front.announce.defaultItemsPerPage| 10| Taille de pagination (front-office)|
| announce.indexer.enable| true| Activer l'indexation Lucene|
| announce.lucene.minScore| 0.5| Score minimal de pertinence Lucene|

## Base de donnees

| Table| Description|
|-----------------|-----------------|
| announce_sector| Regroupement des categories par secteur|
| announce_category| Categories d'annonces avec parametres de moderation/workflow|
| announce_announce| Les annonces|
| announce_announce_response| Liaison annonces / reponses generic attributes|
| announce_indexer_action| File d'indexation Lucene incrementale|
| announce_search_filters| Criteres de recherche sauvegardes|
| announce_portlet_last_announces| Configuration du portlet|
| announce_notify| Suivi des notifications|

## Permissions RBAC

| Ressource| Permissions|
|-----------------|-----------------|
| Secteur| Creer, Modifier, Supprimer|
| Categorie| Creer, Modifier, Copier, Supprimer|
| Annonce| Publier/Depublier, Suspendre, Supprimer, Action workflow|
